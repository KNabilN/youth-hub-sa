

# إصلاح عدم ظهور نموذج الدفع عند استخدام كود خصم

## المشكلة

عند تطبيق كود خصم يغطي كامل المبلغ (أو يجعل `totalAfterDiscount = 0`)، يحاول النظام عرض نموذج Moyasar بمبلغ 0 ر.س. مكون `MoyasarPaymentForm` يحتوي على شرط `if (!Number.isFinite(amount) || amount <= 0) return;` مما يمنع تهيئة النموذج تماماً — فيظهر فقط مؤشر التحميل بشكل دائم دون أن يظهر نموذج الدفع أبداً.

حتى لو لم يكن المبلغ صفراً تماماً، لا يوجد مسار في الكود يتعامل مع حالة "الخصم يغطي كل شيء" مثلما يوجد لحالة "رصيد المنح يغطي كل شيء".

## الحل

### 1. `src/pages/Checkout.tsx` — إضافة مسار "الخصم يغطي كامل المبلغ"

إضافة متغير `discountCoversAll` عندما يكون `totalAfterDiscount <= 0` بدون استخدام منح:

```typescript
const discountCoversAll = !useGrantBalance && totalAfterDiscount <= 0 && discountAmount > 0;
```

عند `discountCoversAll`:
- **لا يظهر** اختيار طريقة الدفع (مثل حالة `grantCoversAll`)
- **لا يظهر** نموذج Moyasar
- زر التأكيد يعمل مباشرة: ينشئ المشاريع والعقود والضمان المالي بمبلغ 0 ثم يوجه لصفحة النجاح
- يسجل استخدام الكود ويفرغ السلة

### 2. `src/pages/Checkout.tsx` — تعديل `handleCheckout`

إضافة كتلة شرطية في بداية الدالة:

```typescript
if (discountCoversAll) {
  // إنشاء المشاريع والعقود لكل عنصر
  // إنشاء escrow بمبلغ 0
  // تسجيل استخدام كود الخصم
  // تفريغ السلة والتوجيه لصفحة النجاح
}
```
